# TO MY THANGA PULLA 👑❤️

> *"You're never a stranger to me. You are my Thanga Pulla, my princess, and no fight can ever change your place in my heart."*

A cinematic, emotional, interactive fairytale website designed and built as a personal gift from a brother to his sister.

---

## ✨ Features

- **Magical 3D Opening Envelope:** A realistic 3D folded pink paper envelope with wax seal, opening flap, and emerging personal letter.
- **8 Emotional Story Chapters:**
  1. *Heyyyy pa...* — Welcome to Your Little Kingdom
  2. *I'm Truly Sorry* — Words from a Brother's Heart
  3. *You're Not a Stranger* — The Unbreakable Bond
  4. *Princess of This World* — Caring for You with a Father's Heart
  5. *Always Special* — More Important Than Any Argument
  6. *Five Little Windows* — 3D Polaroid Frames & Realistic Scrapbook
  7. *My Promises to You* — Action-Backed Brotherly Promises
  8. *The Final Letter* — Forever Your Brother & Forever Warm Hug
- **Interactive 3D Three.js Scenes:**
  - Princess Fairytale Kingdom with floating clouds and butterflies
  - Plush Teddy Bear delivering a heart letter
  - Golden Hourglass turning back time
  - 3D Page-Turning Scrapbook
  - Five Blooming Garden Flowers of Sisterhood
  - Rose-Gold Princess Crown Ceremony
  - Starlight Heart Universe
  - Forgiveness Butterfly on a Blooming Rose
  - Sibling Hugging Bears with photo collage
- **Original Photography Integration:** Real memories framed in 3D Polaroids and interactive lightbox with zoom.
- **Soundtrack Integration:** Persistent audio player featuring *"Unakkenna Venum Sollu"*.

---

## 🛠️ Tech Stack

- **React 18** with **TypeScript**
- **Vite 6**
- **Tailwind CSS 3.4** (Custom High-Contrast Royal Palette)
- **Framer Motion 11**
- **Three.js** (WebGL 3D Interactive Experiences)
- **Lucide Icons**
- **Canvas-Confetti**

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/mohamedumar1807/sorryyyyyyyyy.git

# Navigate to project folder
cd "thanga pulla"

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Build for production
npm run build

# Preview production build locally
npm run preview
```
